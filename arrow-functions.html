Стрелочные функции

Стрелочные функции — это короткий способ записать функцию. Название пошло от символа =>, похожего на стрелку. Это, наверное, самая заметная особенность современного кода на JavaScript.

Синтаксис

Сравним обычную функцию и стрелочную, которые делают одно и то же:

// обычная функция
function sum(a, b) {
  return a + b;
}

// стрелочная функция
const sum2 = (a, b) => {
  return a + b;
};

Слово function пропадает, а между параметрами и телом ставится стрелка. Функцию обычно сохраняют в переменную через const.

Сокращённая запись

Если функция состоит из одного выражения, фигурные скобки и return можно убрать — результат вернётся автоматически. Если параметр один, можно убрать и круглые скобки.

const sum = (a, b) => a + b;
const double = n => n * 2;
const sayHi = () => console.log('Привет!');

console.log(sum(2, 3)); // 5
console.log(double(4)); // 8

Есть одна ловушка: если нужно вернуть объект, его надо обернуть в круглые скобки, иначе фигурные скобки будут считаться телом функции.

const makeUser = name => ({ name: name, active: true });

Стрелки и методы массивов

Больше всего стрелочные функции пригождаются как колбэки для методов массивов map, filter, reduce, find. Код получается коротким и читается почти как обычный текст.

const prices = [100, 250, 40, 900];

const withTax = prices.map(p => p * 1.2);
const cheap = prices.filter(p => p < 200);
const total = prices.reduce((sum, p) => sum + p, 0);

console.log(cheap); // [100, 40]
console.log(total); // 1290

Особенность this

Главное отличие стрелочных функций не в длине записи. У них нет своего this — они берут его из того места, где были созданы. Раньше из-за этого приходилось писать var self = this или использовать bind.

const timer = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++; // this — это объект timer
      console.log(this.seconds);
    }, 1000);
  }
};

timer.start(); // 1, 2, 3 ...

Если бы внутри setInterval была обычная функция, this указывал бы не на timer, и счётчик бы не работал.

Когда стрелки не подходят

  • Как методы объекта, если внутри нужен this этого объекта.
  • Как конструктор: стрелочную функцию нельзя вызвать через new.
  • Когда нужен объект arguments — у стрелок его нет (вместо него можно использовать rest-параметры ...args).
  • Как обработчик события, если внутри используется this для обращения к элементу.

В остальных случаях стрелочные функции можно смело использовать — это нормальный современный стиль.
