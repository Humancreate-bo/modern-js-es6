Модули: import и export

Когда программа растёт, держать весь код в одном файле неудобно. Модули позволяют разбить код на отдельные файлы и явно указать, что каждый файл отдаёт наружу и что берёт из других.

Зачем нужны модули

Раньше в браузере все скрипты подключались через несколько тегов script и делили общую глобальную область видимости. Если в двух файлах была переменная с одинаковым именем, одна затирала другую. Также приходилось следить за порядком подключения файлов.

У модуля своя область видимости: всё, что в нём объявлено, по умолчанию недоступно снаружи. Наружу попадает только то, что явно экспортировано.

Экспорт

Именованный экспорт — перед объявлением пишется export. Из одного файла можно экспортировать сколько угодно значений.

// файл math.js
export const PI = 3.14159;

export function circleArea(r) {
  return PI * r * r;
}

export const square = x => x * x;

Импорт

В другом файле нужные значения импортируются по именам в фигурных скобках. Путь к файлу пишется с расширением.

// файл main.js
import { circleArea, square } from './math.js';

console.log(circleArea(2)); // 12.56636
console.log(square(5));     // 25

// можно переименовать при импорте
import { PI as piNumber } from './math.js';

// или импортировать всё сразу как объект
import * as math from './math.js';
console.log(math.square(3)); // 9

Экспорт по умолчанию

Если файл отдаёт что-то одно главное (например, класс), используют export default. При импорте имя можно выбрать любое, и фигурные скобки не нужны.

// файл User.js
export default class User {
  constructor(name) {
    this.name = name;
  }
}

// файл app.js
import User from './User.js';
const u = new User('Лена');

Во многих командах договариваются использовать только именованный экспорт: так редактор кода лучше подсказывает имена, а при переименовании меньше путаницы.

Модули в браузере

Чтобы браузер понял, что файл — модуль, в тег скрипта добавляют атрибут type="module":

<script type="module" src="js/main.js"></script>
  • Модули всегда работают в строгом режиме.
  • Модульный скрипт загружается отложенно, как с атрибутом defer.
  • Модули не работают при открытии HTML-файла напрямую с диска (через file://) — нужен локальный сервер, например расширение Live Server в VS Code.
