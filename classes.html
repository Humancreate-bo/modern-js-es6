Классы

В ES6 появился синтаксис классов. Внутри JavaScript по-прежнему работает на прототипах, но писать объектно-ориентированный код стало намного проще и привычнее для тех, кто знает Java, C# или Python.

Как было раньше

До ES6 «класс» делали через функцию-конструктор, а методы добавляли в прототип:

function User(name) {
  this.name = name;
}
User.prototype.sayHi = function () {
  console.log('Привет, я ' + this.name);
};

var u = new User('Петя');
u.sayHi();

Код рабочий, но выглядит запутанно, особенно когда появляется наследование.

Объявление класса

Тот же пример с классом. Метод constructor вызывается автоматически при создании объекта через new.

class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    console.log(`Привет, я ${this.name}`);
  }
}

const u = new User('Петя');
u.sayHi(); // Привет, я Петя

Также в классе можно объявить геттеры и сеттеры — методы, которые выглядят снаружи как обычные свойства:

class Rectangle {
  constructor(w, h) {
    this.w = w;
    this.h = h;
  }
  get area() {
    return this.w * this.h;
  }
}

console.log(new Rectangle(3, 4).area); // 12

Наследование

Один класс может расширять другой с помощью extends. Дочерний класс получает все методы родителя и может добавить свои или переопределить существующие. Чтобы вызвать конструктор или метод родителя, используется super.

class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(`${this.name} издаёт звук`);
  }
}

class Dog extends Animal {
  speak() {
    super.speak();
    console.log(`${this.name} лает: Гав!`);
  }
}

new Dog('Шарик').speak();
// Шарик издаёт звук
// Шарик лает: Гав!

Статические методы

Статический метод принадлежит самому классу, а не объектам. Его вызывают через имя класса. Обычно так делают вспомогательные функции.

class MathHelper {
  static average(...nums) {
    return nums.reduce((a, b) => a + b, 0) / nums.length;
  }
}

console.log(MathHelper.average(4, 5, 6)); // 5

Приватные поля

С ES2022 в классах можно объявлять приватные поля. Их имя начинается с #, и обратиться к ним снаружи класса нельзя — будет синтаксическая ошибка.

class BankAccount {
  #balance = 0;

  deposit(sum) {
    if (sum > 0) this.#balance += sum;
  }

  get balance() {
    return this.#balance;
  }
}

const acc = new BankAccount();
acc.deposit(1000);
console.log(acc.balance);  // 1000
// console.log(acc.#balance); — ошибка

Раньше «приватность» обозначали подчёркиванием _balance, но это была только договорённость между программистами — поле всё равно было доступно.
