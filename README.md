# Современный JavaScript (ES6+)

**Сайт:** https://humancreate-bo.github.io/modern-js-es6/

Учебный проект по веб-программированию на тему «Использование CSS-фреймворков».
Тематический сайт из 10 страниц о возможностях современного JavaScript (стандарт ES6 и новее).

## О проекте

Сайт — небольшой справочник для тех, кто знает основы JavaScript и хочет разобраться в современном синтаксисе.
На каждой странице разобрана одна тема с примерами кода.

| Страница | Файл | О чём |
|---|---|---|
| Главная | `index.html` | Что такое ES6+, история версий (таблица), видео, список тем |
| let и const | `variables.html` | Новые способы объявления переменных, сравнение с `var` |
| Стрелочные функции | `arrow-functions.html` | Синтаксис `=>`, краткая запись, поведение `this` |
| Деструктуризация | `destructuring.html` | Деструктуризация массивов и объектов, spread и rest |
| Шаблонные строки | `template-strings.html` | Подстановка `${}`, многострочный текст, интерактивный пример |
| Классы | `classes.html` | `class`, наследование, статические и приватные поля |
| Промисы и async | `async.html` | Промисы, цепочки `then`, `async`/`await`, `fetch` |
| Модули | `modules.html` | `import` / `export`, модули в браузере |
| ES2020+ | `es2020.html` | `?.`, `??`, новые методы массивов и объектов |
| Контакты | `contacts.html` | Форма обратной связи, об авторе, источники |

## Используемые технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `aside`, `section`, `footer`, `figure`)
- **CSS3** — собственные стили поверх фреймворка, методология БЭМ, CSS Grid и Flexbox
- **[Water.css](https://watercss.kognise.dev/)** v2 — classless CSS-фреймворк (подключён через CDN jsDelivr)
- **JavaScript (ES6+)** — бургер-меню, обработка форм, интерактивный пример на странице «Шаблонные строки»

## Адаптивность

Вёрстка сделана по подходу **mobile-first**. Контрольные точки:

- до 768px — мобильная версия (бургер-меню, одна колонка);
- от 768px — планшеты (горизонтальное меню, подвал в три колонки);
- от 992px — десктопы (основной контент и сайдбар в две колонки).

Water.css автоматически включает тёмную тему, если она выбрана в системе.

## Структура проекта

```
modern-js-es6/
├── index.html ... contacts.html   # 10 страниц сайта
├── css/
│   ├── style.css       # собственные стили (исходник)
│   └── style.min.css   # минифицированная версия (подключена на страницах)
├── js/
│   ├── script.js       # скрипт (исходник)
│   └── script.min.js   # минифицированная версия
├── img/                # логотип и изображения (WebP + JPEG, 3 размера)
├── README.md
└── read.md
```

## Как запустить

1. Скачать репозиторий:
   ```
   git clone https://github.com/Humancreate-bo/modern-js-es6.git
   ```
2. Открыть файл `index.html` в браузере.

Сборка и установка зависимостей не нужны. Для просмотра нужен интернет, так как Water.css подключается с CDN.
