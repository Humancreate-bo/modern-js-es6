Полезное из ES2020 и новее

После ES6 язык меняется каждый год. Изменения небольшие, но некоторые из них очень упрощают повседневный код. На этой странице собраны возможности, которые я использую чаще всего.

Опциональная цепочка ?.

Если в цепочке свойств какое-то звено равно null или undefined, обычное обращение выдаст ошибку. Оператор ?. в этом случае просто вернёт undefined.

const user = { name: 'Вика', address: null };

// console.log(user.address.city); — TypeError
console.log(user.address?.city);  // undefined
console.log(user.getAge?.());     // undefined, метода нет — ошибки тоже нет

Оператор нулевого слияния ??

Оператор ?? возвращает правое значение, только если левое равно null или undefined. Этим он отличается от ||, который срабатывает на любое «ложное» значение, включая 0 и пустую строку.

const count = 0;

console.log(count || 10); // 10 — ноль посчитался «ложным»
console.log(count ?? 10); // 0  — ноль остался

Также есть сокращённые присваивания ??=, ||= и &&= (ES2021).

Новые методы массивов

Полезные методы массивов из новых стандартов
МетодВерсияЧто делает
includes()ES2016Проверяет, есть ли элемент в массиве
flat()ES2019Делает вложенный массив плоским
at()ES2022Берёт элемент по индексу, поддерживает отрицательные: at(-1) — последний
findLast()ES2023Ищет элемент с конца массива
toSorted()ES2023Сортирует, не меняя исходный массив
 
const nums = [3, 1, 2];

console.log(nums.includes(2)); // true
console.log(nums.at(-1));      // 2
console.log(nums.toSorted());  // [1, 2, 3]
console.log(nums);             // [3, 1, 2] — исходный не изменился

Работа с объектами

Методы Object.entries() и Object.fromEntries() позволяют превратить объект в массив пар и обратно. Благодаря этому к объекту можно применить методы массивов.

const prices = { хлеб: 50, молоко: 90, сыр: 400 };

const expensive = Object.fromEntries(
  Object.entries(prices).filter(([, price]) => price > 60)
);

console.log(expensive); // { молоко: 90, сыр: 400 }

Числа

  • Разделитель разрядов (ES2021): 1_000_000 читается легче, чем 1000000.
  • Тип BigInt (ES2020) для очень больших целых чисел: 9007199254740993n.
  • Оператор возведения в степень ** (ES2016): 2 ** 10 равно 1024.
