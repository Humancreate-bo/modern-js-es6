Деструктуризация, spread и rest

Деструктуризация — это способ «распаковать» массив или объект в отдельные переменные одной строкой. Рядом с ней обычно рассказывают про оператор ..., который в зависимости от места работает как spread (распаковка) или rest (сборка остатка).

Деструктуризация массивов

Переменные берут значения по порядку. Ненужные элементы можно пропустить запятой.

const colors = ['красный', 'зелёный', 'синий'];

const [first, second] = colors;
console.log(first);  // 'красный'
console.log(second); // 'зелёный'

const [, , third] = colors;
console.log(third);  // 'синий'

Удобный трюк — обмен значений двух переменных без временной переменной:

let a = 1;
let b = 2;
[a, b] = [b, a];
console.log(a, b); // 2 1

Деструктуризация объектов

Для объектов значения берутся не по порядку, а по имени свойства. Можно переименовать переменную и задать значение по умолчанию.

const student = { name: 'Олег', group: '141', age: 20 };

const { name, age } = student;
console.log(name, age); // 'Олег' 20

const { group: groupNumber, city = 'не указан' } = student;
console.log(groupNumber); // '141'
console.log(city);        // 'не указан'

Можно доставать и вложенные свойства:

const order = { id: 7, client: { name: 'Ира', phone: '+7 900 000-00-00' } };
const { client: { name: clientName } } = order;
console.log(clientName); // 'Ира'

Деструктуризация в параметрах функции

Самое частое применение на практике. Если функция принимает объект с настройками, его сразу можно разобрать в параметрах:

function showUser({ name, age = 18 }) {
  console.log(`${name}, ${age} лет`);
}

showUser({ name: 'Катя', age: 21 }); // Катя, 21 лет
showUser({ name: 'Дима' });          // Дима, 18 лет

Оператор spread

Spread «раскладывает» массив или объект на отдельные элементы. С его помощью удобно копировать и объединять массивы и объекты.

const a = [1, 2];
const b = [3, 4];
const all = [...a, ...b];       // [1, 2, 3, 4]
const max = Math.max(...all);   // 4

const defaults = { theme: 'light', lang: 'ru' };
const settings = { ...defaults, theme: 'dark' };
console.log(settings); // { theme: 'dark', lang: 'ru' }

Spread делает поверхностную копию: вложенные объекты не копируются, а передаются по ссылке.

Оператор rest

Rest выглядит так же — три точки, но делает обратное: собирает «оставшиеся» значения в массив или объект.

function sum(...numbers) {
  return numbers.reduce((s, n) => s + n, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

const [head, ...tail] = [10, 20, 30];
console.log(tail); // [20, 30]

const { password, ...publicData } = { login: 'admin', password: '123', role: 'user' };
console.log(publicData); // { login: 'admin', role: 'user' }

Запомнить разницу просто: если ... стоит там, где значения используются, — это spread; если там, где значения принимаются, — это rest.
