Шаблонные строки

Шаблонные строки записываются не в кавычках, а в обратных апострофах `...` (клавиша с буквой «Ё»). Они позволяют вставлять в строку переменные и писать текст на несколько строк.

Подстановка значений

Раньше строки собирали через плюс, и в длинных выражениях легко было запутаться в кавычках и пробелах:

const name = 'Анна';
const age = 19;

// старый способ
const text1 = 'Меня зовут ' + name + ', мне ' + age + ' лет.';

// шаблонная строка
const text2 = `Меня зовут ${name}, мне ${age} лет.`;

Внутри ${...} можно писать не только имя переменной, а любое выражение: арифметику, вызов функции, тернарный оператор.

const price = 500;
const count = 3;
console.log(`Итого: ${price * count} руб.`); // Итого: 1500 руб.
console.log(`Скидка ${count >= 3 ? 'есть' : 'нет'}`); // Скидка есть

Многострочный текст

В обычных кавычках перенос строки приходилось писать как \n. В шаблонных строках можно просто нажать Enter. Это удобно, например, для генерации HTML-разметки:

const product = { title: 'Ноутбук', price: 55000 };

const card = `
  <div class="card">
    <h3>${product.title}</h3>
    <p>Цена: ${product.price} руб.</p>
  </div>
`;

document.body.insertAdjacentHTML('beforeend', card);

Осторожно: если вставлять в HTML то, что ввёл пользователь, можно получить XSS-уязвимость. Для текста от пользователя лучше использовать textContent.

Тегированные шаблоны

Это более продвинутая возможность. Перед шаблонной строкой можно написать имя функции, и она получит части строки и подставленные значения отдельно. Так работают, например, некоторые библиотеки для стилей и SQL-запросов.

function highlight(strings, ...values) {
  return strings.reduce((result, str, i) =>
    result + str + (values[i] !== undefined ? `[${values[i]}]` : ''), '');
}

const user = 'Иван';
console.log(highlight`Пользователь ${user} вошёл`);
// Пользователь [Иван] вошёл

Попробуйте сами

Введите имя и нажмите кнопку. Приветствие собирается с помощью шаблонной строки и зависит от текущего времени.

Код, который выполняется при нажатии:

const greeting = hour < 12 ? 'Доброе утро' : hour < 18 ? 'Добрый день' : 'Добрый вечер';
output.textContent = `${greeting}, ${name}! Сейчас ${hour} ч.`;
