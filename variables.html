Переменные: let и const

До ES6 в JavaScript был только один способ объявить переменную — ключевое слово var. В ES6 добавили let и const, и сейчас в новом коде var почти не встречается. Разберёмся, почему.

Чем был плох var

У var нет блочной области видимости. Переменная, объявленная внутри if или цикла, видна и снаружи. Кроме того, var можно объявить повторно, и ошибки не будет:

if (true) {
  var message = 'Привет';
}
console.log(message); // 'Привет' — переменная «вылезла» из блока

var count = 1;
var count = 2; // никакой ошибки, старое значение просто потерялось

Ещё одна странность — «поднятие» (hoisting). Переменную var можно использовать до объявления, и вместо ошибки получится undefined. В большой программе такие вещи приводят к трудноуловимым багам.

Ключевое слово let

let объявляет переменную, которая существует только внутри блока { ... }, где она создана. Повторно объявить её в том же блоке нельзя.

let score = 10;
score = 15; // менять значение можно

if (score > 12) {
  let bonus = 5;
  console.log(score + bonus); // 20
}
console.log(bonus); // ReferenceError: bonus is not defined

Особенно удобно let ведёт себя в циклах: на каждой итерации создаётся своя переменная. Классическая задача с setTimeout внутри цикла с let работает так, как ожидаешь.

for (let i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// выведет 1, 2, 3 (а с var вывело бы 3 раза число 4)

Ключевое слово const

const — это переменная, которую нельзя переприсвоить. Значение задаётся сразу при объявлении.

const PI = 3.14;
PI = 3; // TypeError: Assignment to constant variable.

Важный момент: const запрещает менять саму переменную, но не содержимое объекта или массива. Добавлять элементы в массив, объявленный через const, можно.

const fruits = ['яблоко'];
fruits.push('груша'); // так можно
console.log(fruits); // ['яблоко', 'груша']

fruits = []; // а так нельзя — ошибка

Что использовать

Общее правило, которого придерживается большинство разработчиков:

  1. По умолчанию пишите const.
  2. Если значение переменной нужно менять (счётчик, накопитель в цикле), используйте let.
  3. var в новом коде не используйте совсем.

Такой подход сразу показывает читателю кода, какие значения будут меняться, а какие нет. Линтер ESLint даже умеет подсказывать, где let можно заменить на const.
